Summary
I made page about Companies and their cartoons using  HTML and CSS.

For the layout, I used Flexbox for the header to separate the logo and the menu, and for the company cards so they stand in one row and have the same height.

I used CSS Grid for the main structure to split the page into a main section on the left and a sidebar on the right, and for the movie gallery to arrange the posters nicely. Everything is done without floats or frameworks like Bootstrap.
